---
name: ip-cleanroom
description: Clean-room rules for LiveSheet so no patent, copyright or trademark of commercial math tools is infringed. Use before writing any spec, code, test or doc that was inspired by Mathcad, Mathematica or Maple.
---
Read docs/IP-POLICY.md first. Short rules:
1. Ideas and math are free; expression is not. Describe behaviour in own words.
2. Specialists read public docs; the developer and tester never do. Spec is the only bridge.
3. No vendor names in product, UI, file formats or code identifiers. Nominative mention in docs only.
4. No proprietary file formats, assets, example worksheets, help text, or keyword sets copied 1:1.
5. Only permissive dependencies (MIT/BSD/Apache/LGPL-dynamic). No GPL/AGPL.
6. Patents: do not implement a feature *because* a vendor patented it. If a spec resembles a known patented UI technique, flag it in decisions.md for human/legal review.
7. When unsure: stop, write the question in docs/board/decisions.md.
