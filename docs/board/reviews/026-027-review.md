## Environment findings (not code defects)
1. IMPORTANT for Theo's machine: all 1323 files under .venv carry the macOS "hidden" flag
   (`ls -lO` shows `hidden`; `find .venv -flags hidden`), including the Qt platform plugins. Qt cannot
   enumerate plugins, so `QApplication()` aborts ("Could not find the Qt platform plugin offscreen")
   and the real app would not start either, with .venv as is. Fix: `chflags -R nohidden .venv`
   (I did not touch the venv). I worked around it by copying PySide6/Qt/plugins to the scratchpad and
   setting QT_PLUGIN_PATH / QT_QPA_PLATFORM_PLUGIN_PATH.
2. The real plist (~/Library/Preferences/com.livesheet.LiveSheet.plist) is modified by running the
   suite: per-file runs flagged test_gui_helpers, test_matrix_dialog, test_plot, test_solve_b,
   test_spec023_review, test_stats_tests (not reproducible every run; a concurrent agent or a late
   cfprefsd flush may add noise). These tests do not isolate QSettings. Developer to isolate them.
   026/027 files did not touch it when run alone (one unattributable touch of the 027 review file in
   one run, not repeatable).
